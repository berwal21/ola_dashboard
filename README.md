 Ola Ride Data Analysis Dashboard

Technologies: Power BI, Power Query, DAX  

 Project Summary

Developed an interactive Power BI dashboard to analyze 50,000+ Ola ride records and evaluate booking trends, revenue performance, customer preferences, and ride cancellations. Cleaned and transformed raw data using Power Query, created a structured data model with a Calendar table, and developed DAX measures to calculate key performance indicators (KPIs), including Total Rides, Total Revenue, Cancellation Rate, Average Fare, and Ride Completion Rate.

Designed an interactive dashboard using KPI cards, slicers, filters, bar charts, line charts, and donut charts to present insights clearly. Analyzed peak booking hours, preferred payment methods, cancellation patterns, and revenue trends to identify business performance patterns and support data-driven decision-making.

 Key Insights

- Identified peak booking hours to understand customer demand patterns.
- Analyzed customer payment preferences to identify commonly used payment methods.
- Evaluated cancellation trends to understand booking performance and potential service issues.
- Monitored revenue, average fare, and completed rides through interactive KPIs.
- Enabled dynamic analysis by date and other available dimensions using slicers and filters.

## Skills Demonstrated

Data cleaning and transformation, data modeling, DAX calculations, KPI development, interactive dashboard design, exploratory data analysis, and business intelligence reporting.
